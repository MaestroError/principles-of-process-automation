# Process specification examples

The same Five O vocabulary applies across these assignments. The examples are illustrative prescriptive specifications, not validated operating procedures. Covering all five dimensions does not prove feasibility or completeness.

| Example | Role assignments | What it demonstrates |
|---|---|---|
| [Library loan](./manual-library-loan.md) | Entirely people, using paper records | Recurring manual work, distinct owner and escalation recipient, non-digital evidence. |
| [Research-record collection](./ai-research-records.md) | Entirely AI agents within the process boundary | Finite work, bounded AI ownership, AI-to-AI escalation, deadline and unresolved outcomes. |
| [Article-share workflow](./article-share-post-workflow/README.md) | AI/software and a human publisher | Parent/child composition and a locally required human approval. |
| [General post image](./linkedin-post-image.md) | AI/tools and a human reviewer | Automation-specific allocation and open-ended selection. |
| [Article-share image](./linkedin-article-share-image.md) | Software/AI and a human reviewer | Narrower selection rules and explicit resource dependencies. |

## Reading the examples

Use [TERMS.md](../TERMS.md) for shared definitions. An operator performs an activity; a process owner holds responsibility for the whole process within defined authority; an escalation recipient handles a particular class of situations beyond an operator's limits. The recipient is not automatically the owner or a human.

The two first examples use the core vocabulary without translating manual or automation terminology. Their assignments differ; their specification dimensions do not. The remaining examples preserve automation work from the framework's development. Their numeric autonomy grids, human checkpoints, and tools are local application choices, not universal specification requirements.

Continuous processes also fit the framework: specify the condition maintained, permitted operating states, conditions for suspension and resumption, active maintenance of a safe state, and observation over a declared interval rather than inventing a scheduled finish.
